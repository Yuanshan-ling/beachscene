# 海滩场景｜Unity URP Shader 与 VFX 原型

基于 Unity URP 制作的海滩环境效果原型。项目围绕干湿沙滩过渡、近远海水层次、顶点海浪、岸边泡沫与海浪飞沫展开，练习 Shader Graph、VFX Graph 和场景光照氛围的组合表现。

> **引擎版本：** Unity 6.3 LTS  
> **渲染管线：** URP 3D  
> **开发语言：** C#

## 项目内容

### 沙滩与海水材质

- 使用 Shader Graph 制作干沙与湿沙的颜色、粗糙度与过渡效果。
- 将海面划分为近海与远海，建立不同的颜色、透明度与细节层次。
- 使用顶点位移实现基础海浪起伏，并叠加水面光照波纹。
- 制作岸边泡沫带，通过遮罩、透明度与动态纹理表现海水与沙滩的交界。

### 海浪飞沫 VFX

- 使用 VFX Graph 制作沿海岸线生成的海浪飞沫粒子。
- 配置粒子的初始位置、向上喷射、重力、阻力、湍流与横向扰动。
- 通过粒子生命周期控制尺寸、颜色和透明度变化。
- 使用平面碰撞控制粒子落地位置，避免飞沫穿过沙滩。

### 场景氛围

- 调整太阳方向与偏暖色光，建立傍晚海滩的主光氛围。
- 通过全局色调与远处轻雾处理海天层次与景深感。
- 组织海面、沙滩、泡沫和飞沫的渲染关系，保证场景层次清晰。

## 打开项目

1. Clone 本仓库到本地。
2. 使用 Unity Hub 打开项目根目录。
3. 推荐使用 **Unity 6.3 LTS** 打开。
4. 项目首次打开时会自动尝试载入主场景。
5. 如未自动打开，请在 Project 面板中手动打开：

   `Assets/Scenes/beachscene.unity`

6. 在 Unity Editor 中点击 Play 运行。

```text
